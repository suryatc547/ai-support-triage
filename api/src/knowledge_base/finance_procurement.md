# Finance & Procurement Support — Routing Policy

## Team: Admin Team
**Contact:** admin@test.com
**Department:** Finance & Procurement

## Scope of Support

Route any ticket to the Admin Team when the email contains topics related to:

- **Purchase Approvals**: Any request to approve or raise a purchase order (PO), procurement request, or vendor quote.
- **Invoice Processing**: Invoices pending approval, payment delays, or vendor billing disputes.
- **Expense Reimbursements**: Employee expense claims, reimbursement status, travel expense approvals.
- **Budget Queries**: Questions about department budgets, cost center allocations, or financial forecasting.
- **Contract Renewals**: Software license renewals, vendor contract extensions, subscription management.
- **Subscription Billing**: Company-level SaaS subscription issues (not employee personal accounts).

## Escalation Triggers

Route **immediately** to Admin Team if the email mentions:
- "urgent payment", "overdue invoice", "vendor threatening to stop service"
- Any amount above $10,000 requiring executive approval

purchase, PO, invoice, payment, expense, reimbursement, vendor, budget, procurement,
