# IT Support — Routing Policy

## Scope of Support

Route any ticket to the IT Admin team when the email contains topics related to:

- **Hardware Requests**: New laptops, monitors, keyboards, mice, headsets, docking stations, or peripherals.
- **Software Installation**: Requests to install or update software, tools, or IDEs on company devices.
- **Network & Connectivity**: VPN issues, Wi-Fi problems, network drives not accessible, slow internet.
- **Account & Access**: Password resets, MFA setup (non-security incidents), new system access requests, account unlocks.
- **Device Provisioning**: Setting up new employee machines, device enrollment, MDM/device management.
- **Email Setup**: Configuring email clients, shared mailboxes, calendar access.
- **Printer Issues**: Printer connectivity, paper jams, driver installation.
- **Software Licenses**: Requesting or managing software license keys.
- **Remote Desktop**: Remote access setup, RDP configuration, remote work tools.

## Escalation Triggers

Route to **Security Team** instead if the email mentions:
- "account hacked", "someone else logged in", "suspicious login", "phishing"
